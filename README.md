# 🏴󠁧󠁢󠁳󠁣󠁴󠁿 Tartan Generator (Генератор тартана)

Веб-приложение для создания аутентичных шотландских орнаментов (тартанов) с использованием математически точного алгоритма саржевого переплетения и палитры **STA** (Scottish Tartans Authority).

## ✨ Особенности

*   **Подлинное переплетение**: Симуляция текстуры саржи 2/2 (diagonal twill), создающая характерный диагональный рубчик.
*   **Нотация Thread Count**: Поддержка стандартной записи тартанов (например, `G/24 B4 K24`).
*   **Палитра STA**: Использование каноничных цветов: Blue (B), Green (G), Black (K), Red (R), Tan (T), Purple (P), Yellow (Y), Grey (N), White (W).
*   **Режимы тональности**: 
    *   *Modern*: Яркие, насыщенные цвета.
    *   *Historical*: Приглушенные, «растительные» красители.
*   **Генерация и Рандом**: Создание случайных гармоничных узоров на основе исторических сетов.
*   **История**: Сохранение последних созданных паттернов в ленте для быстрого сравнения.
*   **Экспорт**: Скачивание готового узора в формате PNG с разрешением до 2048px.

## 🚀 Как запустить

Проект написан на «чистом» стеке (Vanilla JS), поэтому не требует сборки или установки зависимостей.

1.  Скачайте файл `index.html`.
2.  Откройте его в любом современном браузере.

## 🛠 Техническая часть

### Алгоритм плетения
Для отрисовки используется HTML5 Canvas API. Цвет каждого пикселя вычисляется на основе пересечения нитей основы (**warp**) и утка (**weft**):
```javascript
const warpOnTop = ((xi + yi) % 4) < 2; // Логика саржи 2/2
```
Этот подход позволяет добиться реалистичного смешивания цветов в местах пересечения нитей.

### Система Thread Count
Приложение парсит строки вида `R/56 K4 R4 K4 G32`. 
*   **Слэш (`/`)** обозначает "якорь" (pivot) — точку симметрии, от которой узор зеркально разворачивается.
*   **Буква** — код цвета.
*   **Число** — количество нитей данного цвета.

## 🎨 Поддерживаемые коды цветов

| Код | Описание | Код | Описание |
| :--- | :--- | :--- | :--- |
| **B** | Blue (Синий) | **P** | Purple (Фиолетовый) |
| **G** | Green (Зеленый) | **Y** | Yellow (Желтый) |
| **K** | Black (Черный) | **N** | Grey (Серый) |
| **R** | Red (Красный) | **W** | White (Белый) |
| **T** | Tan (Коричневый) | **O** | Orange (Оранжевый) |

*Префиксы **D** (Dark) и **L** (Light) позволяют использовать оттенки (например, **DB** — темно-синий).*

## 📖 Примеры известных кланов (встроены в поиск)

*   **Black Watch**: `B/4 B16 K4 B16 G32 K4 G32 B16 K4 B16 B/4`
*   **Royal Stewart**: `R/56 K4 R4 K4 G32 K4 W2 K4 G32 K4 R4 K4 R/56`
*   **MacLeod**: `Y/24 K4 R4 K4 Y/24`
