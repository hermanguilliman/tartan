# Tartan Generator

Веб-приложение для создания аутентичных шотландских орнаментов (тартанов) и обоев для смартфонов и компьютеров.

## Возможности

### Генератор узоров
- Подлинное саржевое переплетение 2/2 (diagonal twill)
- Нотация Thread Count (STA): `G/24 B4 K24`
- 14 базовых цветов с тёмными/светлыми вариантами
- Режимы тональности: современный, исторический, тёмный, светлый
- История паттернов с превью

### Обои для устройств
- **8 пресетов**: iPhone 15/16, iPhone Pro Max, Android, Android QHD, Full HD, QHD, 4K UHD, Ultrawide
- **4 стиля оформления**:
  - *Заполнение* — тартан на весь экран
  - *Мозаика* — бесшовное повторение паттерна
  - *Центр* — чёткий тартан по центру на размытом фоне
  - *Градиент* — затемнение сверху и снизу для виджетов
- Настраиваемая виньетка с регулировкой силы
- Скачивание в полном разрешении устройства

### Экспорт
- PNG до 2048px (режим узора)
- PNG в разрешении устройства (режим обоев, до 3840x2160)

## Запуск

Проект не требует сборки. Откройте `index.html` в браузере.

## Коды цветов STA

| Код  | Цвет       |      | Код  | Цвет       |
| :--- | :--------- | :--- | :--- | :--------- |
| B    | Синий      |      | P    | Фиолетовый |
| G    | Зелёный    |      | Y    | Жёлтый     |
| K    | Чёрный     |      | N    | Серый      |
| R    | Красный    |      | W    | Белый      |
| T    | Коричневый |      | O    | Оранжевый  |
| C    | Малиновый  |      | M    | Пурпурный  |
| E    | Бирюзовый  |      | I    | Индиго     |
| S    | Сланцевый  |      |      |            |

Префиксы: **D** = тёмный (DB — тёмно-синий), **L** = светлый (LB — светло-синий).
